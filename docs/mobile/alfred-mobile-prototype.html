AALFREDMOBILE PROTOTYPE

A clickable layout prototype of the phone app. It covers the modules that exist in the web app: Home, Expenses, Reminders, Work (freelance and office), Goals, Design, Secrets and Settings.

  1. Tick a reminder on Home or in Reminders.
  2. Add a transaction from Expenses and watch the totals move.
  3. Open Work → a project → an invoice.
  4. More → Secrets, then any four digits.
  5. More → Settings to switch between the 12 grounds.

All figures and names are sample data. Nothing is saved.
